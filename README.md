# Transferencias Personales

Trabajo practico grupal de la materia **Topicos de Programacion** de la carrera **Ingeniería Informática** en la **Universidad Nacional de La Matanza**.

Este proyecto consiste en desarrollar una aplicación en C para analizar datos de transferencias personales internacionales.
A partir de archivos CSV, el programa carga la información en memoria y permite obtener estadísticas como totales por país, continente, saldos trimestrales, variaciones anuales, promedios.
